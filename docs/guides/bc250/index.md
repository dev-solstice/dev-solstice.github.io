# BC-250

AMD BC-250은 원래 암호화폐 채굴용 컴퓨트 유닛으로 만들어졌지만, Zen2 CPU 코어와 RDNA2 GPU를 한 칩(플레이스테이션5 칩으로 추정)에 담은 저렴한 게이밍로 취미 커뮤니티에서 재활용되고 있습니다. 이 섹션은 BC-250을 실제로 조립하고, 리눅스를 올리고, 로컬 LLM 기기로 튜닝하는 전 과정을 다룹니다.

## 이 문서의 관점

BC-250에 관한 기존 영문 자료들은 세부 설정(리눅스 커맨드, 바이오스 등)이 부족하여 활용에 어려움이 있습니다. 해당 가이드는 흩어져 있는 정보들을 통합하고 직접 수동 검증을 진행하여, 실제 작동 가능한 절차를 한국어로 정리하였습니다.
