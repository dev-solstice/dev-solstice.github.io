# BC-250

AMD BC-250은 원래 클라우드 게이밍 서버용 컴퓨트 유닛으로 만들어졌지만, Zen2 CPU 코어와 RDNA2 GPU를 한 칩에 담은 저렴한 미니PC 보드로 취미 커뮤니티에서 재활용되고 있습니다. 이 섹션은 BC-250을 실제로 조립하고, 리눅스를 올리고, 게이밍 머신으로 튜닝하는 전 과정을 다룹니다.

## 이 문서의 관점

인터넷에 떠도는 BC-250 관련 정보는 파편화되어 있고, 특히 LLM에게 물어보면 출처가 불분명하거나 이미 틀린 절차를 그럴듯하게 답하는 경우가 많습니다. 이 가이드는 실제로 손으로 검증한 절차와 수치만 정리하는 것을 목표로 하며, 불확실한 부분은 불확실하다고 명시합니다.
